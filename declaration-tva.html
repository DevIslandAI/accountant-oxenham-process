Faire la déclaration de TVA mensuelleDo the monthly VAT return

Chaque fin de mois, Oodit déclare à la MRA la TVA du mois précédent, pour chaque société. Il l'a montré pour la TVA sur les ventes.At the end of every month, Oodit declares the previous month's VAT to the MRA, for each company. He showed it for VAT on sales.

Lancer le rapport TVA dans SageRun the VAT report in Sage

Dans Sage Intelligence : Report Manager, VAT Annex, MRA VAT Supplies. Il lance le rapport du premier au dernier jour du mois.In Sage Intelligence: Report Manager, VAT Annex, MRA VAT Supplies. He runs the report from the first to the last day of the month.

Exemple : fin août, il a fait la déclaration de juillet (du 1er au 31 juillet). Fin septembre, il fera celle d'août.Example: at the end of August he did July's return (1 to 31 July). At the end of September he will do August's.

À demanderTo ask
  • Pouvez-vous nous envoyer le rapport « MRA VAT Supplies » d'un mois, et le fichier déposé à la MRA pour ce même mois ?Can you send us the "MRA VAT Supplies" report for one month, and the file filed with the MRA for that same month?
  • Pour combien de sociétés faites-vous la déclaration chaque mois, et combien de temps prend une déclaration ?For how many companies do you file each month, and how long does one return take?
  • Vous avez montré la TVA sur les ventes. Qui prépare la TVA sur les achats : vous, ou quelqu'un de l'équipe ?You showed VAT on sales. Who prepares VAT on purchases: you, or someone in the team?
